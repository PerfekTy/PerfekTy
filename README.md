## 🚀 What I'm building

**[Saloonik](https://saloonik.com)** is an appointment booking and management app for service businesses: salons, clinics and studios. Appointment calendar, client base, SMS reminders and stats in one place.

- 🧑‍💻 Co-founder, board member and co-author of the app
- 🌐 Web platform built with React (React Router) and our own API SDK
- 📱 Currently building the mobile app for Android, iOS and tablets with Expo

Running a service business? Give it a try, the first 7 days are free.
